# LosersQ

A VCT Americas 2026 manager sim by **Freshbatch**.

You beat ENVY at Ascension and took their slot. Build the roster, run the office, handle sponsors, scrim, veto, and try to make Champions.

**Play:** https://deadpancakelinus.github.io/losersq/

## Requirements

- Chrome or Edge 113+ on a Windows, Mac or Linux computer (WebGPU required)
- About 1 GB of free space for the dialogue model, downloaded on first launch and cached after that

Characters are voiced by Qwen 2.5 1.5B running locally in the browser through WebLLM. Nothing is sent to a server.
